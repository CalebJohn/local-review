# Phase 3 Plan 03-02: Hunk-Level Staging

**Phase:** 3 — Staging Controls (Part 2)
**Goal:** Stage/unstage individual hunks within a diff view

## Requirements
- STAG-03: Stage individual hunks within a diff view
- STAG-04: Unstage individual hunks within a diff view

## Task 1: hunk-level git methods

- `GitRepo::stage_hunk(path: &str, hunk: &DiffHunk)` 
  1. Get HEAD content for file
  2. Apply hunk's Delete+Insert changes to HEAD content
  3. Write modified content to index via add_frombuffer or equivalent

- `GitRepo::unstage_hunk(path: &str, hunk: &DiffHunk)`
  1. Get staged content from index
  2. Reverse the hunk's changes in staged content  
  3. Write back to index

## Task 2: Diff view hunk staging UI

- Track current_hunk_index: Option<usize> in App when in diff view
- n/N navigation already sets scroll position; map scroll to hunk index
- Visual indicator for current hunk (highlight in diff render)
- 's' in diff view → stage current hunk
- 'u' in diff view → unstage current hunk

## Task 3: Refresh diff after hunk staging

- After staging a hunk, recompute diff_content (shows remaining unstaged)
- After unstaging a hunk, recompute diff_content  
- Preserve scroll position if possible
