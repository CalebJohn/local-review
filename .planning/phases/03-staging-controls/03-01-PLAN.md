# Phase 3 Plan: Staging Controls

**Phase:** 3 — Staging Controls
**Goal:** Stage/unstage at file and hunk granularity with live sidebar refresh

## Requirements
- STAG-01: Stage entire file from the review UI
- STAG-02: Unstage entire file from the review UI
- STAG-03: Stage individual hunks within a diff view
- STAG-04: Unstage individual hunks within a diff view
- VIEW-09: Sidebar refreshes to reflect current git status after staging operations

## Plan 1: File-Level Staging + Live Refresh

### Task 1: Add git module staging methods
- Add to `GitRepo`:
  - `stage_file(path)` — calls `index.add_path(path)`
  - `unstage_file(path)` — removes from index
- Add `changed_files()` re-fetch after staging
- Error handling for each method

### Task 2: Extend App with staging Message + keybindings
- Add Message variants: `StageFile`, `UnstageFile`, `StageHunk`, `UnstageHunk`
- Add `stage_hunk_index: Option<usize>` to track current hunk under cursor
- Keybindings: `s` = stage, `u` = unstage (context-dependent)

### Task 3: Live sidebar refresh (VIEW-09)
- After any staging op, re-fetch changed files and update `app.files`
- Preserve `selected_index` if file still exists
- Reset to 0 if selected file removed by staging

### Verification
1. Stage a file → status changes from M/A to blank in sidebar, or new file shows staged
2. Unstage a file → staged file shows M in sidebar
3. q exits cleanly

## Plan 2: Hunk-Level Staging

### Task 1: stage_hunk and unstage_hunk in GitRepo
- `stage_hunk(path, hunk)` → apply partial diff to HEAD content, add to index via buffer
- `unstage_hunk(path, hunk)` → reverse the hunk in staged content

### Task 2: Diff view hunk staging UI
- Show hunk boundaries visibly in diff view
- Current hunk indicator via `stage_hunk_index`
- Visual feedback when staging hunks (brief flash or color)

### Task 3: Refresh diff after hunk staging
- After staging a hunk, recompute diff_content
- Show remaining unstaged hunks in the file

### Verification
1. Stage a single hunk → file shows partially staged in sidebar
2. Unstage a hunk → restored in diff view
3. All VIEW-09 tests pass

## Dependencies
- Plan 1 first (file-level is prerequisite)
- Plan 2 stacks on Plan 1

## Test Strategy
- Unit tests for each git staging method
- Integration via --test flag or manual verification

## Success Criteria (from ROADMAP)
- [ ] Stage file → sidebar updates (VIEW-09)
- [ ] Unstage file → sidebar updates
- [ ] Stage hunk → diff refreshes showing remaining
- [ ] Unstage hunk → diff refreshes
- [ ] All operations reflect immediately (VIEW-09)
