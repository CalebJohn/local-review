   Implement App:
   - `pub fn new() -> Result<Self, Box<dyn std::error::Error>>`:
     - Open repo with GitRepo::open(".")
     - Load files with repo.changed_files()
     - If files is non-empty, auto-select first file and load its diff (call load_diff_for_selected)
     - Initialize: selected_index=0, diff_scroll=0, focus=Sidebar, should_quit=false

   - `fn load_diff_for_selected(&mut self)`:
     - Get the FileEntry at self.selected_index
     - Determine if staged-only via entry.is_staged_only()
     - If staged-only (VIEW-06): old = self.repo.head_content(path), new = self.repo.index_content(path)
     - If unstaged (VIEW-05): old = self.repo.index_content(path), new = self.repo.workdir_content(path)
     - Handle ContentResult variants:
       - If EITHER side returns ContentResult::Binary: set self.diff_content = Some(binary_diff_content(path))
       - If both sides return ContentResult::Text or ContentResult::NotFound: extract the text (NotFound -> None, Text(s) -> Some(s)), call compute_diff_content(path, old_text.as_deref(), new_text.as_deref())
     - Handle errors by setting diff_content to None
     - Reset diff_scroll to 0

     - MoveUp: if selected_index > 0, decrement. If focus is Sidebar, also call load_diff_for_selected (for immediate preview).
     - MoveDown: if selected_index < files.len() - 1, increment. If focus is Sidebar, also call load_diff_for_selected.
     - SelectFile: call load_diff_for_selected, set focus to DiffView
     - ScrollDiffUp: if diff_scroll > 0, decrement
     - ScrollDiffDown: increment diff_scroll (clamped to max content lines minus viewport, but exact clamping happens in view)
     - SwitchFocus: toggle between Sidebar and DiffView (Tab key)
     - Quit: set should_quit = true

   - `pub fn total_diff_lines(&self) -> usize`: count total lines across all hunks in diff_content (used for scroll clamping)

2. Update src/main.rs to full TEA event loop:

   ```rust
   mod app;
   mod git;
   mod diff;
   mod ui;

   use app::{App, Message, Focus};
   use ratatui::crossterm::event::{self, Event, KeyCode, KeyEventKind};

   fn main() -> Result<(), Box<dyn std::error::Error>> {
       let mut terminal = ratatui::init();
       let result = run(&mut terminal);
       ratatui::restore();
       result
   }

   fn run(terminal: &mut ratatui::DefaultTerminal) -> Result<(), Box<dyn std::error::Error>> {
       let mut app = App::new()?;
       loop {
           terminal.draw(|frame| ui::view(frame, &app))?;

           if let Event::Key(key) = event::read()? {
               // CRITICAL: Filter for KeyEventKind::Press to avoid duplicate events (Pitfall 2)
               if key.kind == KeyEventKind::Press {
                   let msg = match app.focus {
                       Focus::Sidebar => match key.code {
                           KeyCode::Char('q') => Some(Message::Quit),
                           KeyCode::Char('j') | KeyCode::Down => Some(Message::MoveDown),
                           KeyCode::Char('k') | KeyCode::Up => Some(Message::MoveUp),
                           KeyCode::Enter => Some(Message::SelectFile),
                           KeyCode::Tab => Some(Message::SwitchFocus),
                           _ => None,
                       },
                       Focus::DiffView => match key.code {
                           KeyCode::Char('q') => Some(Message::Quit),
                           KeyCode::Char('j') | KeyCode::Down => Some(Message::ScrollDiffDown),
                           KeyCode::Char('k') | KeyCode::Up => Some(Message::ScrollDiffUp),
                           KeyCode::Tab => Some(Message::SwitchFocus),
                           KeyCode::Esc => Some(Message::SwitchFocus), // Back to sidebar
                           _ => None,
                       },
                   };
                   if let Some(msg) = msg {
                       app.update(msg);
                   }
               }
           }

           if app.should_quit {
               break;
           }
       }
       Ok(())
   }
   ```
