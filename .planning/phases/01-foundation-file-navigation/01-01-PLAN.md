   ```rust
   #[derive(Debug, Clone, Copy, PartialEq)]
   pub enum ChangeKind {
       Equal,
       Insert,
       Delete,
   }

   #[derive(Debug, Clone)]
   pub struct DiffLine {
       pub kind: ChangeKind,
       pub old_lineno: Option<u32>,
       pub new_lineno: Option<u32>,
       pub content: String,
   }

   #[derive(Debug, Clone)]
   pub struct DiffHunk {
       pub old_start: u32,
       pub new_start: u32,
       pub lines: Vec<DiffLine>,
   }

   #[derive(Debug, Clone)]
   pub struct DiffContent {
       pub path: String,
       pub hunks: Vec<DiffHunk>,
       pub is_binary: bool,  // true when either side is binary
   }
   ```

2. Create src/diff/mod.rs:
   - `pub mod types;` re-export
   - `use similar::{TextDiff, ChangeTag, DiffOp};`
   - `pub fn compute_hunks(old: &str, new: &str, context_lines: usize) -> Vec<DiffHunk>`:
     - Create TextDiff::from_lines(old, new)
     - Call diff.grouped_ops(context_lines) to get groups of operations
     - For each group, iterate ops and build DiffLine entries:
       - DiffOp::Equal: iterate old[old_index..old_index+old_len], create DiffLine with kind=Equal, old_lineno=Some(old_idx+1), new_lineno=Some(new_idx+1)
       - DiffOp::Delete: iterate old[old_index..old_index+old_len], create DiffLine with kind=Delete, old_lineno=Some(i+1), new_lineno=None
       - DiffOp::Insert: iterate new[new_index..new_index+new_len], create DiffLine with kind=Insert, old_lineno=None, new_lineno=Some(i+1)
       - DiffOp::Replace: first emit Delete lines for old range, then Insert lines for new range
     - Set hunk old_start/new_start from first op in group
     - Use `diff.old_slices()` and `diff.new_slices()` to get the actual line content for each index
     - NOTE: similar's `TextDiff::from_lines` splits on newlines. Access content via indexing into the original slices returned by the diff.
   - `pub fn compute_diff_content(path: &str, old_content: Option<&str>, new_content: Option<&str>) -> DiffContent`:
     - Treat None as empty string "" (handles new/deleted files per Pitfall 5 from research)
     - Call compute_hunks with context_lines=3 (standard git diff context)
     - Return DiffContent { path: path.to_string(), hunks, is_binary: false }
   - `pub fn binary_diff_content(path: &str) -> DiffContent`:
     - Return DiffContent { path: path.to_string(), hunks: vec![], is_binary: true }
     - Used by App when ContentResult::Binary is returned from git content methods

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem -> App | App reads files from local git working directory; user already has filesystem access |
| git2 (libgit2) -> App | C library binding; memory safety relies on git2 crate's FFI correctness |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | workdir_content reads arbitrary paths | accept | Tool only reads within git repo workdir; user already has full filesystem access to their own repo |
| T-01-02 | Denial of Service | Large file content read into memory | accept | Local tool; user is diffing their own files. No external input vector. |
| T-01-03 | Tampering | git2 FFI memory safety | accept | git2 crate is widely used (rust-lang org maintained), libgit2 is battle-tested C library |
| T-01-04 | Denial of Service | Binary file passed to diff algorithm | mitigate | Null-byte check in first 8KB of content; binary files short-circuit to ContentResult::Binary before reaching similar |
</threat_model>
