# Quick Task 260424-001: Split Sidebar into Staged and Unstaged Sections

## What Changed

The sidebar now renders two distinct sections instead of a single flat file list:

- **Staged (N)** - files with index changes (HEAD vs index diff)
- **Unstaged (N)** - files with working directory changes (index vs workdir diff)

Files with both staged and unstaged changes appear in both sections.

## Files Modified

- `src/app.rs` - Added `SidebarSection` enum, replaced single `files` Vec with `staged_files`/`unstaged_files`, updated navigation to cross section boundaries, diff selection uses section context
- `src/ui.rs` - Added `sidebar_section_areas()` for proportional layout, `render_file_list()` helper, split sidebar rendering into two blocks with counts
- `src/main.rs` - Updated mouse handling to detect clicks in staged vs unstaged areas using `MouseClickStagedSidebar`/`MouseClickUnstagedSidebar` messages

## Key Design Decisions

- **Section-relative indexing**: `selected_index` is relative to the active section, not a global index
- **Proportional layout**: Each section gets space proportional to its file count, with a minimum of 3 rows
- **Seamless crossing**: j/k at section boundaries automatically transitions between staged and unstaged
- **Correct diff context**: Staged section always shows HEAD-vs-index; unstaged always shows index-vs-workdir
